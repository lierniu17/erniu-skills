# 八个学习方法的落地细则

每个方法给三样：**原理一句话**（为什么有效）、**落地动作**（这条 skill 里具体做什么）、**自检信号**（出现什么迹象说明违反了它）。
方法不是知识点，是操作规范。看完就忘等于没用，所以每条都要落成动作。

---

## 1. 费曼学习法

**原理**：讲不清 = 没懂。把知识压成通俗语言时，被术语掩盖的漏洞会自动暴露。

**落地动作**
- **先立约**：开场就告诉他「学完你要讲给我听」。这个期待必须在学习前建立——事先知道要讲，学习时的组织方式会变；学完才提，增益消失（Kobayashi 2024：事先 g≈0.48，事后 g≈−0.02）。
- 阶段 6 固定执行，且**必须闭卷**：收走速查表、地图、笔记。边看边讲是复述，不是检索。
- 我的角色不是装傻问「什么是 X」，而是找漏洞 + 追问三题（反例 / 去掉前提 / 换场景）+ 拒绝代讲。
- 不允许「背定义」，要求「用你自己的话说，且举一个自己的例子」。
- 讲到卡住的地方记下卡点，回填到核心卡。
- 讲完给一道**迁移题**（没见过的场景），答不出说明只记住了路径。

**自检信号**
- 用户满口术语，一个例子都举不出来 → 没真懂。
- 用户讲得流畅但换一个场景就不会 → 只背了路径，没掌握机制。
- 用户一边翻资料一边讲 → 这次费曼无效，重来。

**证据边界**：费曼本人没写过「四步法」，这是后人包装；真正起作用的是自解释（g≈0.55，Bisra 2018）+ 检索。而「讲给 AI 听」的增益目前偏小（知识题有效、调试类任务无效，量级约 5%，Chen 2026 BJET），所以它不是主力手段，主力是阶段 3。

## 2. 遗忘曲线 / 间隔重复

**原理**：记忆按指数衰减。在「快忘但还没忘」的临界点做**主动回忆**，衰减速度会被重置得更慢。

**落地动作**
- 阶段 7 用 `scripts/review_schedule.py` 生成节点（默认 1/2/4/7/15/30 天）。
- 每个节点写 3 个闭卷问题，而不是「复习第 N 章」。
- 复习方式是**先默写/先回答，再对照**，不是重读笔记（重读产生的熟悉感是假的）。
- 错题簿里的 ❌ 项自动进下一轮复习，占该轮问题的一半。

**自检信号**
- 复习 = 把笔记再读一遍 → 无效，改成闭卷自测。
- 只在考试前突击 → 违反曲线，改成多轮短时。

## 3. 巨人学习法

**原理**：领域里最好的人已经把知识结构、常见坑、判断标准压缩过了。先吸收被验证的，再改造。

**落地动作**
- 阶段 1 的地图骨架只能来自：权威教材目录、官方大纲、认证考试大纲、顶级课程 syllabus、领域经典综述。**不许自己拍脑袋搭结构。**
- 阶段 5 的第 5 个坑位固定是「大师输出」，选标准：在这个领域有 10 年以上实操、有可验证成果、讲的是判断力而非名词。
- 学大师不是抄结论，是抄**提问方式和取舍标准**：他遇到这个问题先看什么、忽略什么。

**自检信号**
- 地图是我编的，没有一个来源对得上 → 重做。
- 只收集大师金句，没有他做判断的过程 → 学了个寂寞。

## 4. 学习金字塔

**原理**：听讲/阅读的留存率最低，讨论、实践、教别人的留存率最高。被动输入制造「我在学习」的错觉。
**注意**：金字塔上那些 5%/10%/90% 是伪数据——溯源到 NTL 时对方承认「找不到支持这些数字的原始研究」（Masters 2013, *Medical Teacher*）。**只保留方向，禁止引用百分比。**

**落地动作**
- 全部阶段禁止「我给你讲 40 分钟」这种输出方式。讲授必须短（一个核心点 ≤ 5 分钟），紧接着就是练习或提问。
- 每次学习会话至少有一次「用户主动产出」：答题、写代码、画图、口头讲。
- 讨论优先：用户提出反对或疑问时，不急着纠正，先让他说完整。

**自检信号**
- 一次会话我讲了 3000 字，用户回了 3 句「懂了」→ 被动输入，无效。
- 用户全程在看，没动手 → 立刻切到阶段 3。

## 5. 西蒙学习法

**原理**：注意力分散到多个主题时，每个主题都停在「刚入门」的浅层。集中一段时间单点突破才可能到专业水准。
**注意**：「6 个月」是流行说法，不是实证结论；一万小时定律也被误读（Macnamara 2019：一半顶级小提琴手不到一万小时；刻意练习对学业表现的解释力仅约 4%）。保留「单主题 + 时间盒」这个动作，别背书数字。

**落地动作**
- 阶段 0 明确时间盒（默认 6 周；用户想 6 个月也行，但必须写出周期）。
- 一次只服务一个主题。用户想同时学 A 和 B → 让他排序，先做第一个。
- 周路线按模块切开，每周只推进一个模块，不跳跃。
- 新主题的诱惑出现时，记到「以后想学」清单，不立刻开工。

**自检信号**
- 路线表里三个主题交替出现 → 违反。
- 学了两周换方向 → 回到阶段 0 重定契约。

## 6. 刻意练习

**原理**：重复已会的动作只是巩固舒适区。有效练习需要：明确目标 + 在薄弱点上 + 即时反馈 + 纠错重做。

**落地动作**
- 阶段 3 的题目必须打靶：优先出在错题簿和 ⚠️ 项上，不刷已 ✅ 的。
- 每题给即时反馈（对/错 + 为什么），不等一轮结束再统一讲。
- 错误按类型归因（概念缺失 / 混淆 / 记忆模糊 / 边界不清），不同误因用不同补救动作。
- 重做机制：答错的题隔 2–3 题后换个角度再问一次。

**自检信号**
- 用户连对 6 题还在同一难度 → 没在练，在爽。
- 只在整段学完后才测验 → 反馈太迟，纠错成本变高。

## 7. 学习区模型（舒适区 / 学习区 / 恐慌区）

**原理**：太简单不成长，太难直接放弃。成长发生在「跳一跳够得着」的区间。定量版本就是「85% 规则」：错误率约 15% 时学习效率最高（Wilson 2019, *Nature Communications*）。

**落地动作**
- 阶段 0 把验收标准定在「略高于当前能力」的具体任务上。
- 阶段 3 用正确率做仪表：**目标 85%**。> 90% 加难；连续 2 错降到 70–75% 再往上爬；< 50% 说明前置缺失，不是难度问题。
- 阶段 2 的核心点如果用户一听就会 → 说明选低了，往上换。
- 恐慌信号（用户说「完全听不懂」「算了」）出现时，立刻退一层，补前置，不硬推。

**自检信号**
- 全程「懂了懂了」→ 在舒适区。
- 全程「啊？」→ 在恐慌区。
- 只有偶尔卡一下、卡完能自己走通 → 对了。

## 8. 布鲁姆深度学习法（记忆→理解→应用→分析→评价→创造）

**原理**：记住不等于会用。真正掌握要能拆解、能评判、能改造。

**落地动作**
- 阶段 0 验收标准必须写明目标层级，至少到「应用」：
  - 记忆：能说出定义（不够）
  - 理解：能解释为什么
  - 应用：能在新场景里用出来
  - 分析：能拆出组成部分和关系
  - 评价：能判断好坏、说出适用边界
  - 创造：能改造、能组合出新方案
- 阶段 3 的出题按层级递进：是什么 → 为什么 → 换个场景怎么做 → 这个方案有什么问题 → 你会怎么改。
- 阶段 6 追问「这个观点对吗 / 有没有更好的办法」把用户推到评价与创造层。

**自检信号**
- 用户能背定义但换个例子就懵 → 停在记忆层。
- 学完没有产生任何「我觉得这里可以改」的想法 → 没到深度层，但也不必强求每个主题都到创造层。

## 组合使用：一条时间线（三天）

| 时间 | 动作 | 主要方法 |
|---|---|---|
| D1 · 开场 | 立「学完要讲」的约 | 费曼（教学期待，必须前置） |
| D1 | 前测 5 题（先错一次） | 前测 / 生成效应（见附录） |
| D1 | 定契约、找骨架、画地图 | 巨人学习法 + 西蒙 + 学习区 |
| D1 | 只学 3–5 个核心点，每个带最小例子 | 学习金字塔（边学边练）+ 具体例子 |
| 睡眠 | 不加新内容 | 巩固 |
| D2 | 问答 8–10 题，后段交错 | 刻意练习 + 学习区（85%）+ 布鲁姆 |
| D2 | 闭卷重建 → 出速查表 | 学习金字塔（先提取再总结） |
| D3 | 闭卷讲 + 迁移题 | 费曼 + 布鲁姆（应用/创造） |
| D3 | 选 5 个资源、排周路线 | 西蒙 + 巨人 |
| D+1/2/4/7/15/30 | 闭卷自测（含前测原题） | 遗忘曲线 + 主动回忆 |

## 附录：两个不在原清单里、但证据更强的机制

这两个是从研究文献里补进来的，作用大于清单里的一半方法（尤其大于学习金字塔和西蒙的数字部分）。

### 前测（pretesting / errorful generation）
学**之前**先答题，哪怕几乎全错，后续学得更好。元分析效应 g≈0.34~0.54（Boustani & Shanks 2022；St. Hilaire 2024），个别实验里甚至优于学完再测。
机制：错误答案制造「缺口」，让后续信息有了挂载点；同时把注意力提前导向关键处。
要求：必须**随后给出正确答案**，否则只有挫败没有学习。

### 交错练习（interleaving）
把**易混**的类型混着练，而不是一类练完再下一类。总体 g≈0.42，视觉类别 0.67，数学 0.34，词汇表反而 -0.39（Brunmair & Richter 2019）。大样本课堂实验：61% vs 38%（Rohrer 2020, d=0.83）。
它练的是**判断该用哪个**——分块练习永远练不到这一步，因为你动手前已经知道答案属于哪一类。
边界：只在「相似易混」之间混；新手先做一小段分块再交错；交错更费时间，别压缩思考。
